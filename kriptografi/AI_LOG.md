# AI Log

- **Alat:** AI assistant menggunakan Copilot SDK di VS Code.
- **Tujuan:** Menyusun komponen hash kata sandi, pengujian otomatis, dan dokumentasi untuk tugas fondasi kriptografi.
- **Ringkasan perintah:** Meminta pengerjaan tugas pada folder `kriptografi` sesuai ketentuan minimum, lalu meminta penyesuaian konsep produk menjadi toko top-up game.
- **Bagian yang dipakai atau diubah:** Implementasi scrypt pada `passwords.js`, tes otomatis pada `test_passwords.js`, dan dokumentasi kebutuhan/rancangan/cara menjalankan pada `README.md`, termasuk penyesuaian deskripsi dan kebutuhan keamanan untuk toko top-up game. Implementasi awal Python diganti menjadi JavaScript sesuai permintaan agar tidak menggunakan Python. Semua bagian dibuat untuk tugas ini dan harus ditinjau serta dipahami oleh mahasiswa.
- **Cara memeriksa:** Jalankan `node --test test_passwords.js` dari folder `kriptografi`; periksa pula alur implementasi dan batas input sebelum demonstrasi.
